# 🚀 Space Memory Game
---
## Technologies Used
- HTML
- CSS
- JavaScript
---
## Description

Create a planet-themed Memory Game where players flip cards to find matching pairs. The game will test the player's memory by having them remember the location of different planets and space objects. The goal is to match all pairs to win, with a challenge of having a limited number of attempts.
---
## User Stories

- As a user, I want to flip space cards to find matching pairs.
- As a user, I want matching cards to stay visible.
- As a user, I want to see my number of moves/attempts.
- As a user, I want to restart the game with a reset button.
